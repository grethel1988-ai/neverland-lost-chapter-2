# 永無島的失落篇章：公主、謊言與隱密樹屋

永無島三部曲第二部｜國小國語文第二學習階段（中年級）遊戲式線上測驗。

## 執行
直接用瀏覽器開啟 `index.html`，或在此資料夾執行 `py -m http.server 8000` 後開啟 http://localhost:8000 。

## 結構
- `index.html`：畫面結構（封面、選夥伴、劇情、答題、失敗、證書）
- `css/style.css`：叢林部落 × 日系 RPG 風格（沿用第一部規範，改為深綠配色）
- `js/game.js`：劇情、夥伴台詞、抽題（指標保證機制）、拖曳互動、F2/F3/F4
- `js/bank_mc.js`：150 題選擇題（解析自兩份 docx 題庫）
- `js/bank_drag.js`：拖曳題（配對／填空／分類／排序）

## 關卡與指標
| 關卡 | 指標 |
|---|---|
| 第一關 虎蓮公主的刺青解密 | 4-Ⅱ-2、4-Ⅱ-3、4-Ⅱ-4 |
| 第二關 海盜史密的混亂告示牌 | 4-Ⅱ-1、4-Ⅱ-5、四字語詞 |
| 第三關 隱密樹屋的對聯機關 | 5-Ⅱ-2、5-Ⅱ-4、5-Ⅱ-5、5-Ⅱ-6、5-Ⅱ-8 |

難度：叢林探險隊 25 題／羽毛×5、部落勇士 40 題／羽毛×7、樹屋守護者 50 題／羽毛×10。
